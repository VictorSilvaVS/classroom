# 🚀 Classroom: Seu Terminal Grátis na Nuvem

Este repositório foi criado para que você possa estudar **Desenvolvimento Web, Python e Linguagem C** direto pelo seu navegador, sem precisar instalar nada no seu computador!

Esqueça aquela dor de cabeça de configurar variáveis de ambiente, instalar compiladores no Windows ou ter um PC lento travando tudo. Aqui, você ganha um **terminal Linux real** e o VS Code completo na nuvem com apenas um clique.

---

## 🎁 O que você ganha usando o Codespaces?
* **100% Gratuito:** O GitHub oferece 60 horas gratuitas de uso por mês para qualquer estudante.
* **Funciona em tudo:** Você pode programar usando um computador antigo, um Chromebook ou até mesmo direto pelo **celular** conectado à internet.
* **Já vem tudo instalado:** O Python 3, o compilador de C (GCC) e as extensões do VS Code já nascem prontos para você usar.

---

## 🚀 Como Abrir o seu Terminal (Passo a Passo)

Em menos de 2 minutos você estará com o seu ambiente pronto:

1. No topo desta página, clique no botão verde escrito **`<> Code`**.
2. Clique na aba **`Codespaces`**.
3. Clique no botão verde **`Create codespace on main`**.
4. Uma nova aba vai abrir no seu navegador. Aguarde uns segundos enquanto o GitHub prepara o seu computador na nuvem.
5. **Pronto!** O editor de código estará no meio da tela e o seu **Terminal Linux** estará aberto na parte de baixo.
